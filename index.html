Motion Clone

Motion Clone is a Windows calendar and personal planning assistant for personal use. It keeps its application database and runs its AI model on the user's own PC.

Google Calendar and Gmail

With the user's permission, Motion Clone reads selected Google calendars and Gmail messages to display a calendar, identify possible events and prepare suggestions. It reads account identity information to identify the connected account. Gmail access is read-only; attachments are skipped. Outlook messages forwarded into Gmail can be included in the Gmail scan.

The user reviews the saved details of each proposed calendar change before approving it. Calendar write access lets Motion Clone carry out those approved changes and explicitly requested task exports.

Android companion

An optional Android companion forwards notifications from sources explicitly selected by the user, including Google Messages and Discord, to the PC over a private Tailscale connection. The companion requires Android notification access. It does not read the phone's complete SMS or chat history.

Local operation

The app can start at Windows sign-in and continue monitoring in the system tray. The PC must be running and reachable for processing. The user can pause monitoring, disconnect accounts, clear retained assistant data and manage backups.
